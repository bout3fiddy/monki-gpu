# zdisamar style reference

Condensed from zdisamar commit `97b245d382d4ddba4b700b1bdd212e6086348571`.
Source hashes: [provenance.json](provenance.json). License: [LICENSE.zdisamar](LICENSE.zdisamar).
The original guide is not reproduced verbatim here.

MONKI adopts explicit data flow, named inputs and outputs, domain terminology,
blank lines between logical stages, and comments explaining scientific choices.
Ruff and custom AST checks enforce Python style; Zig-specific rules are omitted.
[MONKI's style guide](../../STYLEGUIDE.md) defines the applicable rules and commands.
